## 客户详情编辑态：12 个明细输入框等长（仅 CSS，`frontend/src/views/customers/index.vue`）

### 根因
- `.detail-grid3` 三栏 `1fr 1.4fr 1fr` → 中栏最宽，**跨栏输入框不等长**。
- `.cell-label` 无固定宽度（「联系人」3 字 vs「办公室门牌号」6 字）→ **同栏内输入框起点/长度也参差**。
→ 12 个输入框（含单位类别 select、备注 textarea）长度全都不一样。

### 改动（纯 CSS 3 处，模板不动）
```css
.detail-grid3 { grid-template-columns: repeat(3, 1fr); }   /* ① 三栏等宽（原 1fr 1.4fr 1fr） */
.cell-label { width: 92px; flex-shrink: 0; }               /* ② label 统一定宽 → 输入框起点一致 */
.cell-input { flex: 1; min-width: 0; }                     /* ③ 输入框占满「栏宽−92−间距」→ 全部等长 */
```
- 效果：三栏等宽 + label 定宽 92px → **12 个明细输入框（含单位类别下拉、备注 textarea）像素级等长、左对齐整齐**。
- 展示态共用 `.detail-grid3/.cell-label`：label 定宽后只读「值」也从同一起点对齐，更整齐（无副作用）。
- 名称顶栏（`hero-name-input` 220px）与概要条**不动**（你确认的名称不在此列）。
- 移动端（≤767px）仍降 1 列（已有媒体查询，等宽自动适配）。

### 验证
- `cd frontend && npx vue-tsc --noEmit` + `npm run build`
- 冒烟：展开客户 → 树节点行点「编辑」→ 12 个明细输入框**全部同长同起点**、单位类别下拉与备注 textarea 同宽；展示态只读值左对齐整齐；保存/取消正常。
- 部署待确认后走 update.sh 通道（git 提交 → bundle+vue-dist → scp → update.sh）。
