## 用户确认的边界

- 工作台概览内外网展示一致；模板下载只要求登录与原模块权限，不追加 MFA。
- 保留远端已开放的外网运维/资产功能；客户、销售、系统管理等仍按现有网络限制，MFA 不扩大账号权限。
- 外网敏感报告、密码及配置读取使用远端的账号 MFA 操作令牌校验；拓扑资源和工单图片允许有效 MFA 登录会话，以支持图片和编辑器加载。
- 报告、配置文件、资产表需要在落盘/解析前检查内容，不能仅依赖客户端后缀或 MIME。

有效 MFA 指当前有效登录会话的强度、认证版本、登录时间、验证时间和会话随机量完整；不能只依赖账号已绑定 MFA 标记。报告/配置/密码则要求经现有 MFA 流程签发的短期操作令牌，并校验用户和认证版本；登录 MFA 本身不代替其按次操作验证。重新登录/会话过期后不会继续接受旧 MFA 状态。本轮未改变生产设置。

### 已实现的上传检查

- `utils/upload_content.py:32,94`：落盘前检查可读内容与类型；ZIP 最多 2000 项、单项展开最多 128 MiB、单 XML 最多 16 MiB、大文件压缩比最多 200，总展开预算按端点上限限制且不超过 1 GiB。拒绝路径穿越、绝对路径、重复路径、符号链接、加密包、嵌套普通压缩包和未知成员类型。
- Office OOXML 验证核心部件、XML 实体、宏/嵌入对象/ActiveX/外部数据关系；XLSX 拒绝公式、超出 5000 行/256 列的表。`utils/upload.py:74` 在完整加载工作簿前预检结构与维度。
- 图片由 Pillow 验证真实格式与完整性，最多 2500 万像素；文本配置拒绝二进制伪装及明显网页/脚本内容；PDF 检查头尾及可见活动内容标记。
- `blueprints/asset/config_backups.py:15`、`blueprints/vue_api.py:1494` 两条配置上传补齐统一校验；巡检、工单、旧兼容报告、资产导入复用统一检查；知识库与拓扑上传也接入检查。加密资产导入解密后先检查再写临时文件。
- 报告使用随机独立子目录，配置/照片使用随机存储名，避免同名覆盖；用户可辨识的报告原名保留。`services/submission_version_service.py:114` 不再从版本列表返回配置正文；前端按受控接口获取。
- 下载响应禁缓存、禁止 MIME 嗅探并限制 CSP；PDF 浏览器预览使用 sandbox，拒绝响应显示具体原因。

### 兼容性变化

旧 `.doc/.xls/.vsd` 新上传需要转换为 `.docx/.xlsx/.vsdx` 或 PDF；表格公式需粘贴为值；加密配置包、嵌套包与未在白名单中的成员需要先整理。不会自动扫描、删除或改写存量文件。普通模板下载不要求额外 MFA。

## 部署验收与回滚条件

1. 安装更新后的 requirements；`defusedxml` 为显式依赖。
2. 在服务端设置 `ITSM_TRUSTED_PROXY_NETWORKS` 为真正紧邻应用的反向代理地址（逗号分隔 CIDR/IP；默认 `127.0.0.1,::1`），不能填写任意公网或全部内网作为代理。代理必须覆盖客户端传入的 `X-Real-IP`，并清理转发链；检查监听端口不能绕过代理对公网开放。
3. 验证可信网段 `trusted_networks` 已配置且公网样本无法伪装成私网；本地空配置兼容模式不能作为生产外网隔离证明。`ProxyFix` 的协议/Host 转发仍依赖可信部署拓扑，须同时核验 HTTPS 和 Host。
4. Nginx/CDN 的 `/static/uploads/`、`/uploads/` 不得用 `alias/root` 或缓存绕开 Flask；应转发到应用执行保护。不能只依赖本地测试断言。
5. 用真实外网账号执行：普通模板成功；普通密码会话不能取敏感报告；MFA 操作验证后有权报告成功；过期/撤销会话失败；设备密码有账号权限且操作 MFA 验证通过才可查看；未开放管理接口仍 403；匿名及直接静态路径 404。
6. 回滚应回滚本轮代码/前端产物而保留所有业务数据；若恢复旧代码将重新暴露本报告指出的缺口，须先在边缘代理阻断上传目录直出。未获得操作员授权前不进行生产更新或停服务。

参考：[OWASP File Upload Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html) 建议类型/内容、大小、授权、存储隔离与扫描组合防护；文件签名本身不是完整安全保证。
