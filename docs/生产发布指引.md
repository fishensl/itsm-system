import zipfile, os
out = 'backups/vue-dist-manual.zip'
if os.path.exists(out): os.remove(out)
with zipfile.ZipFile(out, 'w', zipfile.ZIP_DEFLATED) as zf:

## 4. 回滚预案（PG 版，三层）

| 场景 | 操作 |
|---|---|
| 代码/前端问题（无数据变更） | `git checkout c26fdb8` + 还原 `static/app.bak.<ts>` → `systemctl restart itsm` |

| 灾难恢复 | 新机 `scripts/restore.sh`（见 docs/生产迁移手册.md） |
